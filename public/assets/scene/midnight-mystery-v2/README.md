# Midnight observatory, cartoon v2

Approved mysterious lounge: brass celestial arches, moonlit roofs and clock tower, amber lamps, burgundy seating, and a moon-marked side door. The desktop and portrait plates were generated with the built-in imagegen tool from the approved game mockup, removing characters, table, cards, and UI. Portrait has its own composition rather than an enlarged desktop crop.

Runtime plates use high-quality WebP (94, method 6): desktop 1585 × 992, portrait 941 × 1672. They replace only the 100next Midnight backdrop. Full PNG masters and game screenshots are in `../output/100next-mysterious-table-v2/`; prompts and provenance are in `scripts/assets/social-club/mystery-room-generation.json`.

The table stays live 3D with its existing camera, oval projection, piles, card flights, center total, and event timing. Its illustration uses one baked teal celestial atlas, bold zodiac glyphs, simplified walnut grain, and ink rim edges. The cloth shader retains the inward gold-to-red event light while keeping physical lighting restrained so the felt stays teal. No background animation, particles, postprocessing, deck outline, or new per-frame canvas redraw is added. The original Observatory presentation stays available for the stable build.
