# Chair-free master cast playtest

Vince, Finn, June, Edgar, Roxie, Otis, Paloma and Bianca. Each is a newly generated whole-character seated drawing without furniture. These are single neutral masters; the existing Finn/June animation atlases are a separate option. New eight-character animation sheets are not represented by these masters.

The playable test link is `https://100next.pages.dev/?characters=midnight-eight&play=1`. It starts a local table with all eight unique characters, one human and seven CPUs; the existing carousel displays at most four. Setup includes an eight-character choice and the usual seat controls. Online invitation links preserve the cast parameter.

Art created with the built-in image generator using the previously approved Midnight Social Club designs. Finn has a second revision with a smaller head and slimmer adult proportions, exported with a v2 filename to refresh cached artwork. Bianca has an eye correction edit. Sources remain at their generated paths; the manifest records all final source filenames. The original chair-based sheets remain preserved.

Preparation script: `scripts/assets/social-club/prepare-chair-free-masters.py`. It only frames, uniformly scales, exports and assembles already drawn artwork. Every lossless PNG master is 2048 square with at least 512 transparent pixels on all four sides. Runtime WebP copies are lossless and 1024 square. Local full-resolution files and labeled overview are under `../output/100next-character-masters/chair-free-v1` relative to the repository.

Forward-facing seated poses, uncrossed feet, two black/gold card backs at chest height. Retained card fan is image-left; free working hand is image-right. Manifest hand coordinates are in the padded 512-unit drawing and connect the game's existing flying cards to the whole-character masters.
